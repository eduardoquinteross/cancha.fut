# Especificaciones del proyecto

El proyecto sigue Spec-Driven Development (SDD). El orden es **Constitución → SPEC → PLAN → TASKS → implementación → verificación**.

- `docs/constitution.md`: principios obligatorios del proyecto.
- `001-cancha/spec.md`: alcance y comportamiento esperado; fuente de verdad del producto.
- `001-cancha/clarifications.md`: decisiones de alcance y supuestos aprobados.
- `001-cancha/plan.md`: arquitectura, esquema de datos y estrategia de pruebas.
- `001-cancha/tasks.md`: trabajo ordenado, trazable y verificable.
- `001-cancha/verification.md`: resultados ejecutados y trazabilidad de la SPEC.

Los cambios de comportamiento empiezan en la SPEC. Las pruebas no sustituyen la aprobación de cambios de alcance.
